# 🎤 Enhanced Live Voice Word Counter

A modern, feature-rich web application that counts words in real-time as you speak into your microphone. This is an enhanced version of the original [live-voice-word-counter](https://github.com/gsoliman/live-voice-word-counter) with significant improvements in UI/UX, functionality, and accessibility.

## 🌟 Live Demo

**[Try it now!](https://theme613.github.io/enhanced-voice-word-counter/)**

## ✨ Key Enhancements

### 1. **Modern UI Design**
- Beautiful gradient background (purple to pink)
- Glassmorphism effect with backdrop blur
- Smooth animations and transitions
- Professional color scheme and typography
- Responsive design for all devices

### 2. **Custom Trigger Words**

## 🚀 How to Use

1. **Open the app** in a modern browser (Chrome, Edge recommended)
2. **Enter a target word** in the input field (e.g., "um", "like", "hello")
3. **Click "Start Listening"** and allow microphone access
4. **Start speaking** - the counter will update in real-time
5. **View your transcript** and detection history below
6. **Click "Stop Listening"** when done

## 🎯 Use Cases

- **Public Speaking Training**: Track filler words like "um", "uh", "like"
- **Language Learning**: Practice pronunciation and word usage
- **Speech Therapy**: Monitor specific word usage
- **Presentation Practice**: Reduce filler words
- **Fun Challenges**: Count how many times friends say a word
